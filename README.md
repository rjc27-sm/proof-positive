# Proof Positive – short address

https://rjc27-sm.github.io/proof-positive/ forwards to
[Proof Positive](https://rjc27-sm.github.io/style-manual-check/im2026/), which
checks writing against the Australian Government Style Manual.

The tool and its code live in
[rjc27-sm/style-manual-check](https://github.com/rjc27-sm/style-manual-check).
This repo holds only the forwarding page. `404.html` is a copy of `index.html`,
so `/proof-positive/ask` and the other page names go straight to that page.
